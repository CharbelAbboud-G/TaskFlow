# TaskFlow

TaskFlow is a mini Project & Task Management Platform developed during the COMPU-VISION Full-Stack Web Development Internship.

## Project Features

- User authentication
- Project management
- Task management
- Admin CMS
- Public frontend
- REST API

## Technology Stack

- Backend: Node.js + Express.js
- Authentication: JWT
- Database: MySQL or MongoDB
- Admin CMS: React.js
- Public Frontend: Next.js
- API Testing: Postman

## Project Structure

- backend/ - Node.js + Express REST API
- admin/ - React.js Admin CMS
- frontend/ - Next.js public frontend
